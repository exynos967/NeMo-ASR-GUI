本プロジェクトは、**NVIDIA NeMo** フレームワークに基づいたモダンなGUIツールであり、強力な **Parakeet-TDT** シリーズのASR（自動音声認識）モデルをカプセル化しています。動画や音声ファイル内の音声を自動的に認識し、正確なタイムスタンプ付きの **SRT字幕ファイル** を生成します。

モジュール設計を採用して全面的にリファクタリングされ、**多言語インターフェース**、**一括ファイル処理**、および**マルチモデル切り替え**をサポートしており、ユーザーに最も便利なローカル字幕生成体験を提供することを目指しています。

## ✨ 主な機能

*   **多言語インターフェース**: 国際化（I18n）をサポートし、**中国語 / 英語 / 日本語 / 韓国語** のインターフェースをワンクリックで切り替え可能です。
*   **あらゆるメディア形式に対応**: 動画と音声を区別する必要はありません。**MP4, MKV, AVI, MP3, WAV, FLAC** など、ほぼすべての一般的な形式の直接アップロードをサポートしています。
*   **一括文字起こし**: 複数のファイルを一度にアップロードし、キューに入れて自動的に順次処理することができます。
*   **マルチモデルサポート**:
    *   `nvidia/parakeet-tdt-0.6b-v2`: 総合的な能力が高く、英語に強い。
    *   `nvidia/parakeet-tdt_ctc-110m`: 軽量モデルで、推論速度が非常に高速。
    *   `nvidia/parakeet-tdt-0.6b-v3`: より強力な多言語サポート（ヨーロッパ言語など20種類以上に対応）。
*   **柔軟なデプロイ**: 
    *   **クラウドロード**: NVIDIA NGCから最新モデルをワンクリックでダウンロードしてロード。
    *   **ローカルロード**: 既存の `.nemo` モデルファイルのロードをサポートし、再ダウンロードの手間を省きます。
*   **スマートなハードウェアアクセラレーション**: NVIDIA GPU (CUDA) を自動検出し、GPUアクセラレーションを優先的に使用します。GPUがない場合は自動的にCPU実行にフォールバックします。
*   **設定の記憶**: 前回使用したモデル、チャンク設定、言語設定を自動的に保存します。

## 🛠 動作環境

*   **Python**: 3.10 以上 (3.12 推奨)。
*   **FFmpeg**: **個別にインストールし**、システム環境変数（PATH）に設定する必要があります（メディア形式の変換と音声抽出に使用）。
*   **NVIDIA GPU**: (強く推奨) 4GB以上のVRAMを搭載したNVIDIA製グラフィックカード、およびCUDAドライバのインストール。

## 🚀 インストールガイド (Windows)

### 方法1：バッチスクリプトを使用（初心者向け）

1.  本リポジトリをローカルに**クローン/ダウンロード**します。
2.  **`install_dependencies.bat`** をダブルクリックして実行します。
    *   スクリプトが自動的にPython仮想環境を作成します。
    *   必要な依存ライブラリを自動的にインストールします。
3.  インストール完了後、**`launcher.bat`** をダブルクリックしてプログラムを起動します。

> **注意**: GPUアクセラレーションが必要な場合は、「方法2」を参照してPyTorchを手動でインストールし、CUDAバージョンが一致するようにすることをお勧めします。

### 方法2：コマンドラインでの手動インストール（推奨）

1.  **リポジトリのクローン:**
    ```bash
    git clone https://github.com/NINIYOYYO/parakeet-tdt-0.6b-v2-SRT-GUI.git
    cd parakeet-tdt-0.6b-v2-SRT-GUI
    ```

2.  **仮想環境の作成と有効化:**
    ```bash
    python -m venv .venv
    # Windows:
    .\.venv\Scripts\activate
    # Linux/Mac:
    source .venv/bin/activate
    ```

3.  **PyTorchのインストール（重要ステップ）:**
    GPUアクセラレーションを有効にするには、**必ず** [PyTorch公式サイト](https://pytorch.org/get-started/locally/) で、お使いのCUDAバージョンに対応するインストールコマンドを確認してください。
    *例 (CUDA 12.1 環境):*
    ```bash
    pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
    ```

4.  **その他の依存ライブラリのインストール:**
    ```bash
    pip install -r requirements.txt
    ```

5.  **FFmpegのインストール:**
    *   **Windows**: FFmpegのコンパイル済みパッケージをダウンロード・解凍し、`bin` フォルダのパスをシステムの `Path` 環境変数に追加します。
    *   ターミナルを開き `ffmpeg -version` と入力して、出力があればインストール成功です。

6.  **プログラムの起動:**
    ```bash
    python main.py
    ```

## 📖 使用チュートリアル

プログラム起動後、ブラウザで自動的に `http://127.0.0.1:7860` が開きます。

### 1. 初期設定と言語
*   画面上部に言語切り替えメニューがあります。使い慣れた言語（例：「日本語」）を選択してください。
*   プログラムは選択を自動的に記憶します。

### 2. ASRモデルのロード
文字起こし機能を使用する前に、モデルをロードする必要があります。

*   **クラウドモデル (初回使用時に推奨)**:
    1.  「クラウドモデル名」ドロップダウンからモデルを選択します（例：`nvidia/parakeet-tdt-0.6b-v2`）。
    2.  **「クラウドモデルをロード」** ボタンをクリックします。
    3.  *注意：初回ロード時は約1〜2GBのモデルファイルをダウンロードするため、しばらくお待ちください。*

*   **ローカルモデル**:
    1.  すでに `.nemo` ファイルをお持ちの場合、「ローカルモデルのパス」入力ボックスにファイルの絶対パスを入力します。
    *例: C:\Users\models\parakeet-tdt-0.6b-v2.nemo*
    2.  **「ローカルモデルをロード」** ボタンをクリックします。

### 3. 字幕の生成
1.  **「文字起こし / Transcription」** タブに切り替えます。
2.  ファイルアップロードエリアをクリックし、1つまたは**複数**の **動画** または **音声** ファイルを選択します。
3.  (任意) **音声チャンク長 (Chunk Length)** スライダーを調整します。
    *   *推奨値：60〜180秒。チャンクが長いほど文脈がつながりやすくなりますが、VRAMの要求が高くなります。*
4.  **「生成開始 / Submit」** ボタンをクリックします。
5.  右側/下側に現在のファイル名と進行状況がリアルタイムで表示されます。
6.  処理完了後、以下の操作が可能です：
    *   リンクをクリックして生成された `.srt` ファイルをダウンロード。
    *   下のテキストボックスで字幕内容を直接プレビュー。

## ⚠️ よくある質問 (FAQ)

**Q: 「モデルをロード」をクリックした後、画面が固まりました。**
A: 初回クラウドモデルロード時は、バックグラウンドで大きなファイルをダウンロードしています。ターミナル（コマンドライン）ウィンドウを確認すると、詳細なダウンロード進捗バーが表示されています。

**Q: エラー `FileNotFoundError: [WinError 2] 指定されたファイルが見つかりません` が出ます。**
A: 通常、これは **FFmpeg** がインストールされていないか、インストール後にシステム環境変数 PATH に追加されていないためです。

**Q: GPUを持っているのに、CPUで実行されていると表示されます。**
A: PyTorchがCUDAバージョンでインストールされているか確認してください。ターミナルで `python` と入力し、`import torch; print(torch.cuda.is_available())` を実行してください。`False` と出力された場合は、GPU版のPyTorchを再インストールしてください。

**Q: ビデオメモリ不足 (OOM) になります。**
A: 1. 「音声チャンク長」を小さくしてみてください。 2. パラメータ数の少ないモデル（`ctc-110m` など）を選択してみてください。
